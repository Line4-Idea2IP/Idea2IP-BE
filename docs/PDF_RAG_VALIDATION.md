# PDF / RAG 수정 검증 (2026-11-12)

시작 기준은 `feat/#25`, `2737cd4`이며 적용할 AGENTS.md는 없었다.
기존 `gradlew` 실행 권한 변경은 보존하고 이 커밋에서 제외했다.
FastAPI는 `main`, `66f43c4` 및 기존 이미지 질문 관련 미커밋 변경이 있는 상태였다.

## 변경과 계약

- PDF 템플릿 1.1은 저장된 출처 ID를 정렬해 일관된 번호를 부여한다.
  본문의 출처 번호와 마지막 목록은 같은 매핑을 사용한다. API와 저장 데이터의 ID는 유지한다.
  종류는 한글로 표시하고 인터뷰 제목을 읽기 쉽게 변환하며 같은 제목/위치의 중복 출력을 피한다.
- HUMAN_CONTRIBUTION 키와 5개 섹션 순서를 유지하고 제목을 `사용자가 확인한 창작 기여`로 변경했다.
  기존 확정 기여 조립 경로의 직접 창작/직접 수정 구분을 유지한다. 기여 없음 사유를 명시하며,
  사유 변경 시 이전 리포트 편집 문구가 새 사용자 결정을 덮어쓰지 않게 했다.
- Spring의 공식 자료 채택 검증에 HTTPS 공식 호스트, KR, 검토 여부, 적용/발행/수집 날짜와
  본문 SHA-256 검증을 추가했다. 프로젝트/스냅샷 및 제공된 출처 원문 검증은 유지한다.
- READY PDF 다운로드는 기존 저장 파일과 체크섬을 사용한다. 이전 버전을 다시 렌더링하지 않는다.

## 실행 결과

- 실행 중인 서비스 환경으로 `bash gradlew compileJava test` 성공.
  컨텍스트 로드 1, 기여 조립 2, 한글 PDF 렌더링 1, FastAPI 응답 검증 1: 총 5개 성공, 건너뜀 없음.
- 실제 llama.cpp 모델, FastAPI, Spring API와 PostgreSQL로 기존 가상 프로젝트 1에 새 버전 생성.
  v3(id=3), v4(id=4), v5(id=5)는 모두 READY, live, templateVersion=1.1.
- v3: 사용자 수정 후 확정한 창작/수정 문구만 인간 기여에 반영됨. 원본 인터뷰 재분석이 덮어쓰지 않음.
  한글, 5개 섹션, 본문/출처 번호 대응, 내부 ID 비노출, 제목/위치 중복 제거, 공식 지침 미확인 안내 확인.
- v4: 전체 단계를 제외한 뒤 기여 없음 사유가 저장·표시됨. 이후 테스트 기여 결정은 복원함.
- v5: 별도 포트의 FastAPI와 임시 카탈로그를 사용한 명백한 가상 판본만 연결.
  `TEST-ONLY-FICTIONAL-EDITION-2026`, `TEST-ONLY-FICTIONAL-v1`, `가상 검증 발행기관`이며
  실제 공식 자료나 법률 안내가 아님. 채택, 버전 API 저장, PDF의 기관/판본/적용일/원문 URL 확인.
  원래 서비스 설정 복원 및 Spring 재시작 후에도 동일한 판본 정보가 조회됨.
  기본 `samples/legal_catalog.json`의 미검토 자리표시자는 변경하지 않음.
- PDF 텍스트 검사와 렌더링 이미지 육안 확인 완료. 기존 v1의 재다운로드 SHA-256은 전후 모두
  `66c6542ea78c1936f536527c47d710f263bfd9fe93ebfd3970abd01bc6be027b`.
  다른 기존 테스트 계정으로 v1 다운로드 시 HTTP 403.
- 이전 테스트 비밀번호는 보존돼 있지 않아 개발 서버의 기존 JWT 설정으로 두 기존 테스트 계정의
  단기 토큰을 메모리에서 발급했다. 비밀번호 변경이나 토큰 파일 저장은 하지 않았다.
- `git diff --check` 및 최종 diff에서 API 구조, 출처 검증, 확정 기여 우선 반영과 기존 PDF 보존 확인.

원문 응답, 요청 스크립트, PDF, 렌더링은 Git 제외 `build/pdf-revision/`에 있다.
실제 검토된 공식 자료 연결, pgvector 검색 및 새 이미지 관찰은 이번 검증에 포함하지 않았다.
현재 기본 검색 설정은 none이며 실제 검토된 공식 판본이 없어 미확인 안내가 정상 동작한다.
